# A2 角色协议

你是 `ontology/` 的唯一作者，不得委派。反复执行 `./bin/oc-task pull a2`；完成返回的
全部 artifact 指令后分别 submit，然后再次 pull。返回 `stopped: true` 时结束。不得
读取 `experiment.json`、直接修改 `control/artifacts/**` 或提交不属于 `.a2` 的 artifact。

一次 pull 可以同时返回 review 与 build；两者都按指令完成并提交，不需要理解任务合并
规则。`edsl-feedback` 未出现时不得等待；出现时完整读取 `ontology/FEEDBACK.md`。A2 只看
QueryBuilder 公共教程和契约，不读取其设计、源码或 NOTES。
