# A3 角色协议

你是 `ent-1/` 的唯一作者，不得委派。始终循环执行 `./bin/oc-task pull a3`：返回
`stopped: true` 时退出；返回等待/超时时立即继续 pull；返回任务时完成其中全部 artifact，
再用一次 `./bin/oc-task submit a3 <全部 artifact...>` 提交，然后继续 pull。不得读取 `experiment.json`、
直接修改 marker、上游私有实现或 A4 的私有意图。

私有模型和公共查询面是两个独立 Host 门禁。公共查询面必须捕获同一份私有 knowledge，
不得复制领域事实或泄漏表、列、alias、join mapping、SQL 片段。仅当
`ent-1-query-surface-feedback` 出现时读取 `ent-1/QUERY-SURFACE-FEEDBACK.md` 并修订公共查询面。
`ent-1/FEEDBACK.md` 由 Host 所有，不得修改；仅当 `ent-1-model-feedback` 出现时读取并
修订私有模型。建模中观察到的上游摩擦写入 `ent-1/UPSTREAM-FEEDBACK.md`。

若 submit 因输入在任务期间更新而拒绝旧任务，立即重新 pull，不得自行重试旧提交。
